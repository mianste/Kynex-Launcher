# Kynex Launcher v1.4.2

- 下载页多了「投影」。黑曜石农场、小屋、凉亭和石桥都能直接下载，也能先看 3D 预览。
- 在「版本设置 → 投影文件管理」可以打开投影文件夹、导入文件，还能拖动旋转、滚轮放大缩小，看看建筑长什么样。
- 投影用 Minecraft 原版方块来显示。修好了树叶发蓝的问题，樱花叶也会显示原来的粉色。
- 打开整合包、模组、资源包、数据包和光影的安装窗口时，版本列表出来得更快。作者有放截图的话，安装前就能看。
- 修好了新建存档后装不了数据包的问题。现在选择存档就能安装。

## 怎么安装

Windows 10 和 11 的 64 位电脑，下载下方的 `Kynex.Launcher.v1.4.2.Setup.exe`，双击按提示安装。已经装过 Kynex 的玩家，也可以在启动器里检查更新。

[下载源码](https://github.com/mianste/Kynex-Launcher/releases/download/v1.4.2/Kynex.Launcher.v1.4.2.Open.Source.zip) · [反馈问题](https://github.com/mianste/Kynex-Launcher/issues)
