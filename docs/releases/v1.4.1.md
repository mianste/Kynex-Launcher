# Kynex Launcher v1.4.1

- 整合包工坊独立成页，改用标签和按钮导航。任务记录支持逐条删除，使用引导增加工坊、任务记录和汉化步骤。
- 修复下载任务误停在「读取版本配置」以及汉化资源包启用时的 resourcePacks 报错。
- 汉化支持先安装匹配的社区资源包。AI 补译并行处理，复用已通过校验的译文，只重试缺失条目，并显示实时进度。
- 任务取消和失败提醒会自动消失，原因可在「进度与备份」查看。语音服务异常自动重试一次，工坊规划和服务端下载更加稳定。
