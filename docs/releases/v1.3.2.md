# 正式版 v1.3.2

发布日期：2026-11-09

- 版本管理支持添加、切换多个游戏目录，读取已有版本并保存选择。
- 单个版本可自定义运行目录，启动、模组、资源包、光影、存档、数据包和导出统一使用所选路径。
- 修复自动旋转开关打开后不转动的问题，拖动结束、切换窗口或 2D/3D 后均可恢复。
- 优化资源列表加载，复用缓存、合并重复请求并预取下一页；快来源先显示，后到结果不再打乱已有条目。
- 修复五类资源的短字符、中文和符号搜索，以及旧请求覆盖新结果的问题。
- 资源始终保留“安装”入口，同一个资源可以连续安装到多个版本。
- 修复签名 Forge 安装器报错、旧 CurseForge CDN 地址被拒，以及部分下载的证书链兼容问题。
- 整合包文件增加校验缓存与备用地址，下载失败重试时复用已完成文件。
- 全透明主题适配面板、弹窗和下拉菜单，修复展开选项时内容重叠，减少自动字色跳动并改善窗口圆角。
- 音乐自动恢复已登录账号和歌单，增加退出登录，优化二维码准备速度。
- 新闻增加加载占位与图片加载效果，修复顶部空白；其他 Minecraft 游戏不再反复检测。
- 优化皮肤外观同步、按钮与弹窗动效，精简界面提示。

目录切换不会自动搬移旧存档和模组，移除游戏目录仅取消登记。正式版沿用原有安装位置和用户资料。

## 本次升级须知

由于原更新签名私钥已丢失，v1.3.2 启用新的更新签名。旧版用户请从本发布页下载完整安装器，手动覆盖安装一次，之后可继续自动更新。安装时保留原有用户资料。

新版正式更新源：[stable-v2.json](https://github.com/mianste/Kynex-Launcher/releases/download/updater-stable/stable-v2.json)。旧 stable.json 保留原内容，避免旧版本收到无法验证的新签名安装包。
