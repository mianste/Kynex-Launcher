# 正式版 v1.3.3

发布日期：2026-11-09

- 读取模组图标时跳过嵌套依赖，只打开候选图片；支持 Forge、NeoForge 声明的图标路径。

- 模组、资源包、光影和数据包列表底色跟随主题透明度，去掉内层重复底色。

- 资源图标分批显示，优先读取前面的条目；后台更新检查单独限流，避免挡住图标加载。

- 大型整合包先显示文件列表，再后台读取图标和模组信息。
- 缓存未变化文件的模组信息、图标和更新检查指纹，修复反复读取 JAR 导致的卡顿。
- 合并重复资源请求，降低自动刷新频率，后台文件读取最多使用两个线程。

- 修复整合包菜单图标未识别的问题，新导入和已安装实例共用识别规则。
- 修复资源图标上叠加中文名称的问题，加载中或失败时改用通用图标。
- 修复整合包名称带冒号等符号时无法安装的问题。
- 修复较长中文整合包名称被误判为过长的问题。
- 同名整合包仍可重复安装，自动加序号，各实例文件互不覆盖。

v1.3.2 用户可直接自动更新。更早的旧签名版本需手动安装本版一次，之后可继续自动更新。
